# Modular SaaS E-Commerce Platform

A **multi-tenant SaaS e-commerce platform** built with **ASP.NET Core** following **Domain-Driven Design (DDD)**, **Modular Monolith architecture**, and **Event-Driven communication** between modules.

The platform integrates with an external **AuthService** that provides authentication and JWT tokens for the system.

## Planned Architecture

* Modular Monolith
* Domain-Driven Design (DDD)
* Clean Architecture
* Event-Driven module communication
* Multi-tenant SaaS structure

## Tech Stack

* ASP.NET Core
* Entity Framework Core
* JWT Authentication
* Modular Monolith Architecture
